## About
A Python console portal where a user logs in, then adds, views and searches
sales and sees a sales report. Sales are saved in sales.csv.

## Features
- Login (3 attempts)
- Add, view and search sales
- Sales report with Pandas and NumPy (total revenue, average sale, best product, revenue by region)
- File handling with try/except/finally

## Files
- Sales_Dashboard_Portal.ipynb - notebook with code and sample test runs
- sales_portal.py - the same code as a Python file

## How to run
1. Install Python with pandas and numpy.
2. Open the notebook and run all cells, or run: python sales_portal.py
3. Login: admin / 1234
